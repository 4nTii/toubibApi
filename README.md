# Toubib — Medical Appointment Management API

Toubib is a web application for managing medical appointments. It exposes a REST API consumed by a React frontend as well as mobile clients.

---

## Tech Stack

- **PHP 8.4**
- **Symfony 8.0**
- **Doctrine ORM 3** + **Doctrine Migrations**
- **MySQL**
- **Lexik JWT Authentication Bundle 3.2** — JWT-based authentication
- **Nelmio CORS Bundle** — CORS policy management
- **Symfony Mailer** — transactional email delivery
- **Symfony Messenger** — asynchronous message queue handling
- **Symfony CLI 5.16**

---

## Requirements

- PHP >= 8.4
- Composer
- MySQL
- Symfony CLI
- OpenSSL (for JWT key generation)

---

## Installation

Clone the repository then run:

```bash
make
```

This command runs in order:

1. `make setup` — copies `parameters.yml.dist`, installs Composer dependencies and generates JWT keys
2. `make cache-clear` — clears the Symfony cache
3. `make dev` — starts the server via `symfony serve`

---

## Available Commands

| Command            | Description                                         |
| ------------------ | --------------------------------------------------- |
| `make`             | Full setup + cache-clear + symfony serve            |
| `make setup`       | parameters + composer install + jwt                 |
| `make install`     | `composer install` only                             |
| `make parameters`  | Creates `parameters.yml` from `parameters.yml.dist` |
| `make jwt`         | Generates JWT keys in `config/jwt/`                 |
| `make cache-clear` | Clears the Symfony cache                            |
| `make dev`         | Starts the Symfony server                           |

---

## Configuration

Copy the parameters file and fill in your local values:

```bash
cp app/config/parameters.yml.dist app/config/parameters.yml
```

Variables to configure in `parameters.yml`:

- MySQL database connection
- JWT passphrase
- SMTP configuration (Mailer)

## Database

After installation, create the database and run migrations:

```bash
php bin/console doctrine:database:create
php bin/console doctrine:migrations:migrate
```

---

## Authentication

The API uses JWT via `lexik/jwt-authentication-bundle`. Keys are automatically generated by `make jwt` into `config/jwt/` (git-ignored).
